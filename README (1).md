# Smart Chef

##  Було додано та розподілено в окремі папки, щоб не було одного єдиного "God component"

**`store/`** тут створено стан застосунку, тобто всі дані: поточна сторінка, список рецептів,
результати пошуку, стан завантаження, раніше це все було у `main.js`, але тепер зібрано в одному місці

**`services/`** тут зібрані всі сервіси котрі є допоміжним: запити до API рецептів,
логіка навігації між сторінками, й функція для виводу тексту в HTML

**`components/ui/`** це частина інтерфейсу, де кожен файл відповідає за один візуальний елемент: хедер, футер,
картка рецепту, картка страви, и т.д. Вони просто отримують дані і повертають HTML й більше нічого

**`components/containers/`** тут всього два файли: один відповідає за те, що відбувається на сторінці зі стравами (завантаження, пошук), другий за форму контактів (валідація, відправка)

**`pages/`** чотири файли для окремих сторінок сайту: головна, страви, про нас, контакти
